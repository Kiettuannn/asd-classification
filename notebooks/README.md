# Notebooks

Interactive experiment notebooks and standalone remote training notebooks:

- `01_svm_baseline.ipynb`: Phase 1 SVM pipeline and phenotypic analysis.
- `02_gnn_experiments.ipynb`: Exp 3 Graph Convolutional Network (GCN) and Graph Attention Network (GAT) implementations on ABIDE I.
- `05_explainable_brainnet_clip_training.ipynb`: Standalone Kaggle training notebook combining BrainNetCNN connectome encoding, clinical phenotypic text contrastive alignment (InfoNCE), 2x Tesla T4 multi-GPU optimization, Stratified 10-Fold Cross-Validation, aggregate ROC-AUC evaluation, and Yeo 7 network neurobiological explainability.

## Standalone Kaggle Training & Remote CLI Workflow

The notebook `05_explainable_brainnet_clip_training.ipynb` is programmatically generated by `scripts/build_notebook_5.py` and is fully self-contained with zero local backend package dependencies.

### Generating the Notebook

```bash
python scripts/build_notebook_5.py --print-cli
```

### Kaggle CLI Remote Execution

1. Push the notebook and metadata to Kaggle (configured with `enable_gpu: true`, `accelerator: "nvidiaTeslaT4x2"`, and `enable_internet: true`):
   ```bash
   kaggle kernels push -p notebooks
   ```

2. Check remote execution and training progress:
   ```bash
   kaggle kernels status kiettuan/05-explainable-brainnet-clip-training
   ```

3. Download trained model checkpoints, out-of-fold predictions, and publication figures:
   ```bash
   kaggle kernels output kiettuan/05-explainable-brainnet-clip-training -p artifacts/kaggle_outputs
   ```
