# Spatio-Temporal 3D-CNN with Bidirectional Mamba for 4D fMRI

We decided to model 4D resting-state fMRI (rs-fMRI) across the full multi-site ABIDE I dataset (1,112 subjects across 17 institutions) using a decoupled two-stage architecture: a 4-block volumetric 3D-CNN spatial encoder extracting 128-dimensional latent vectors $z_t \in \mathbb{R}^{128}$ from native $64 \times 64 \times 36$ BOLD volumes at each time frame, followed by a 2-layer Bidirectional Mamba (Bi-Mamba) sequence model with Gated Temporal Attention Pooling.

Processing multi-site 4D fMRI natively requires modeling variable chronological sequences ($T \in [78, 300]$) of 3D spatial volumes across heterogeneous scanner sites. Standard autoregressive Transformers scale quadratically $O(T^2)$ with high memory usage and impose causal masking unnatural for offline neuroimaging scans, while LSTMs struggle with long-range temporal retention. Bi-Mamba provides linear $O(T)$ computational scaling and bidirectional sequence scanning across past and future BOLD signals. Decoupling spatial feature extraction from temporal modeling via sequential per-institution caching prevents GPU out-of-memory errors and disk storage exhaustion (~108 GB raw down to <100 MB latent sequences), allowing rapid training across our 4x NVIDIA L4 cluster with PyTorch DistributedDataParallel (DDP), native BF16 mixed precision, padded sequence masking ($T_{\max}=200$), and joint Site-and-Class Stratified 5-Fold Cross-Validation.
